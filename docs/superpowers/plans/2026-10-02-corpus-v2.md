**Goal:** Produce a second EN+HE training corpus ("v2") that is:
- sampled across many CulturaX files
- capped per website
- deduplicated
- normalized to what a keyboard can type

Then A/B it against the current corpus ("v1") and against v1 with only the normalization and dedup applied ("v1c"). Swap in a winner only on explicit user approval.

**Architecture:**
- **Normalization and dedup** (`scripts/clean_corpus.py`) are shared by every path that produces corpus text.
- **The downloader** (`scripts/download_corpora.py`) adds:
  - seeded shard choice
  - seeded per-document sampling
  - a per-site line cap

  It writes to a separate directory.
- **Evaluation:** two small scripts build a conversational test set and leak-free A/B models. Scoring reuses `evaluation/benchmark.py` unchanged.

**Tech Stack:** Python 3.14 `.venv`, HF `datasets` (streaming parquet) + `huggingface_hub` (`hf` CLI), `marisa_trie`, `unicodedata`, pytest.

### Normalization rule

The user asked whether untypeable characters should simply be removed. I agree, split three ways:

| Character class | Examples | Action | Why |
|---|---|---|---|
| Has a typeable counterpart | `’‘` → `'`, `“”„` → `"`, `– — −` → `-`, `…` → `...`, NBSP → space, fullwidth/ligatures (via NFKD), accented Latin `é` → `e`, maqaf `־` → `-`, geresh `׳` → `'`, gershayim `״` → `"` | **map** | It's what the user actually types. |
| Combining marks | nikud, cantillation, Latin accents left after NFKD | **delete** | Not typed; removing them leaves the real word. |
| Invisible formatting (category Cf) | ZWSP, LRM/RLM, soft hyphen, BOM | **delete in place** | Replacing them with a space would split the word around them. |
| Untypeable **letter** | Cyrillic, Arabic, `ß`, CJK | **drop the whole word** | Deleting just the letter makes fake words (`straße` → `strae`). |
| Untypeable **symbol** | `• © ™ « »`, emoji | **replace with a space** | Deleting it would fuse neighbours (`a•b` → `ab`). |

"Typeable" means printable ASCII (U+0020–U+007E) plus the Hebrew letters in `core.keymap.EN_TO_HE_FULL.values()`. `build_quadgrams.py`'s per-language allowed-char filter stays as it is: Latin words in the HE corpus are typeable, but they still don't belong in the HE model.

**Files:**

- Modify: `.gitignore`

**Interfaces:**
- **Produces `TYPEABLE: frozenset[str]`:** printable ASCII plus the Hebrew letters taken from `core.keymap.EN_TO_HE_FULL`. Importing it means putting the project root on `sys.path`, the way `evaluation/benchmark.py` does.
- **Produces `normalize_line(line: str) -> str`.** It applies the table above in this order:
  1. explicit counterpart map (quotes, dashes, `…`, maqaf, geresh, gershayim)
  2. `unicodedata.normalize('NFKD')`
  3. delete combining marks (category `Mn`) and invisible formatting (`Cf`)
  4. per whitespace token: drop the token if any remaining non-typeable character is a letter (category `L*`); otherwise replace each non-typeable character with a space
  5. collapse runs of whitespace and strip

  The explicit map runs first because NFKD would otherwise turn `…` into `...` but leave the curly quotes untouched.
- **Produces `line_key(line: str) -> bytes | None`.** It is the current key logic moved into a function: an 8-byte blake2b hash of the lowercase line with `[\W\d_]+` collapsed, or `None` when no letters remain.
- **Changes `dedup_lines(lines, min_words=0)`** so it calls `normalize_line` before `line_key` and yields the **normalized** line.

### Task 2: Sampled, site-capped download

**Files:**
- Modify: `scripts/download_corpora.py`
- Create: `tests/test_download_sampling.py`

**Interfaces:**
- Consumes `normalize_line` and `line_key` from Task 1.
- **New module constants** (values from Global Constraints): `SEED`, `SHARDS_PER_LANG`, `DOC_KEEP_PROB`, `SITE_CAP`. Each gets a one-line comment giving its reason.
- **`site_of(url: str | None) -> str`:** the lowercase host with every `www` and `m` label removed, so the mobile and desktop versions of a site count as one site. Returns `''` when there is no URL.
- **`round_robin(iterables) -> Iterator`:** yields one item from each iterable in turn and drops each one as it runs out.
- **`sample_lines(docs, keep_prob, seed, site_cap) -> Iterator[str]`.** `docs` is an iterable of dicts with `text` and `url`.
  - It keeps each document when a `random.Random(seed)` draw is below `keep_prob`, with one draw per document in order.
  - It splits text on `\n`, then normalizes and deduplicates using the same logic as `dedup_lines`, with one `seen` set for the whole run.
  - It stops reading a document once its site already has `site_cap` kept lines.
  - The `''` site is exempt from the cap: it bundles many unrelated sites and made up 5.8% of EN lines.
- **`shard_files(lang) -> list[str]`:** all `{lang}/*.parquet` paths at `CULTURAX_REVISION`, listed with `HfApi().list_repo_files(repo_type='dataset', revision=...)`, sorted, then `random.Random(SEED).sample` of `min(SHARDS_PER_LANG, n)`, sorted again.
- **`stream_corpus(lang, out_txt_path, max_lines)`.** It keeps its current behaviour:
  - write to `.tmp`, then rename
  - sha256 of the output
  - a progress line

  It now:
  - opens one streaming dataset per shard with `load_dataset('parquet', data_files='hf://datasets/uonlp/CulturaX@<rev>/<shard>', split='train', streaming=True)`
  - feeds them through `round_robin` and then `sample_lines`
  - logs a warning if the shards run out before `max_lines`
  - also records `shards`, `seed`, `doc_keep_prob` and `site_cap` in the provenance JSON
- **CLI:** `--force` as before, plus `--out-dir DIR` (default `data/`). After `main()` returns, flush stdout and hard-exit (the streaming-hang rule).

**Interfaces:**
- Consumes `normalize_line` from Task 1.
- **`orient(line: str, vocab: set[str]) -> str`.** It returns `line` or `line[::-1]`, whichever has more words in `vocab`, with words stripped of `.,!?:;"'()-`. A tie keeps `line`. Reversing the whole line is right because OpenSubtitles' visual-order Hebrew reverses both the letters and the word order.
- **`load_vocab(path, max_lines=1_000_000, min_count=5) -> set[str]`:** lowercase, normalized, punctuation-stripped words seen at least `min_count` times in the first `max_lines` lines.
- **CLI:** `make_chat_testset.py LANG SRC VOCAB_CORPUS OUT [--group 6] [--max-out 250000]`.
  - It normalizes each non-empty source line and orients it.
  - It writes groups of `--group` lines joined by spaces, so each test line has chat-length context instead of about 5 words.
  - It prints the number of lines written and how many source lines were reversed.
